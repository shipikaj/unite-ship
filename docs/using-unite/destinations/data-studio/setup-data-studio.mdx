# Connect Data Studio

This guide explains how to connect your Data Studio account as a data destination in Unite.

Once connected, you can use your Data Studio data to build pipelines and sync data to your destination.

---

## Before you begin

#### Before connecting Data Studio with Unite, ensure the following:
- A pipeline is created with Data Studio selected as the destination
- You have access to a Google account with Data Studio permissions

##### CREATE A PIPELINE

1. Navigate to  the Pipelines section in Unite
2. Click Create Pipeline
3. Select your preferred Data Source
4. Choose Data Studio as the destination
5. Configure and finish the pipeline setup

##### OPEN DATA STUDIO

You can connect your data in two ways:

A. **From the Status Tab**
   - Open the pipeline.
   - Click Open Data Studio.

B. **From the Schema Tab**
   - Open the pipeline.
   - Navigate to the **Schema** tab.
   - Click Open Report for a specific table/report.

---

## Next step

After connecting your Data Studio account, create a pipeline to begin syncing data.
