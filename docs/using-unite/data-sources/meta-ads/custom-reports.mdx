# Meta Ads Custom Report Fields

**27 metrics · 28 dimensions**

Complete list of Meta Ads fields that can be used in a Unite custom report. Use a custom report when the prebuilt reports do not include the fields you need.

## Dimensions and metrics

There are two types of fields: dimensions and metrics.

- **Dimensions** (types `STRING` and `DATE`) describe or split your data, such as campaign, ad set, country, or placement. Breakdown fields, such as age, gender, and platform, split metrics into more rows.
- **Metrics** (types `INTEGER` and `FLOAT`) are numeric values, such as impressions, clicks, spend, and reach.

## Combining dimensions and metrics

Not every breakdown can be combined with every metric or with every other breakdown. For the supported combinations, see the [Meta Marketing API breakdowns reference](https://developers.facebook.com/docs/marketing-api/insights/breakdowns).

| `cpc` | FLOAT | CPC | The average cost for each click (cost per click). |
