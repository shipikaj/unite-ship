# Shopify Custom Report Fields

**450 fields across 15 resources**

Complete list of Shopify fields that can be used in a Unite custom report. Use a custom report when the prebuilt reports do not include the fields you need.

## Resources and fields

Shopify data is organized into resources, such as orders, products, and customers. Each field ID starts with the resource it belongs to. Select the resource first, then the fields you need from it.

Nested values are flattened into separate fields. For example, `orders.billingAddress.city` is the city of an order's billing address, and fields ending in `_count` and `_precision` are the two parts of a count.
