Google Search Console Custom Report Fields

4 metrics · 7 dimensions

Complete list of Google Search Console fields that can be used in a Unite custom report. Use a custom report when the prebuilt reports do not include the fields you need.

Dimensions and metrics​

There are two types of fields: dimensions and metrics.

  • Dimensions (types STRING and DATE) describe or split your data, such as date, query, page, country, or device.
  • Metrics (type FLOAT) are numeric values: clicks, impressions, CTR, and average position.

CTR is clicks divided by impressions, so it is returned as a fraction. For example, 0.25 means 25%.

Combining dimensions and metrics​

Not every combination of dimensions is supported by Google Search Console. For the supported combinations and data limits, see the Search Analytics API reference.

Google Search Console Dimensions fields​

The Dimensions category of the Google Search Console connector includes 7 fields.

IDTypeNameDescription
siteUrlSTRINGSite URLThe Google Search Console site/property URL.
dateDATEDateThe date of the search performance record (YYYY-MM-DD).
querySTRINGQueryThe search query/keyword search term used by the user.
pageSTRINGPageThe URL/landing page to which search users were directed.
countrySTRINGCountryThe country where the search query originated (in 3-letter ISO code format).
deviceSTRINGDeviceThe type of device used to perform the search (Desktop, Mobile, Tablet).
searchAppearanceSTRINGSearch appearanceHow the site appeared in search results (e.g., AMP article, Review snippet, Web light).

Google Search Console Metrics fields​

The Metrics category of the Google Search Console connector includes 4 fields.

IDTypeNameDescription
clicksFLOATClicksThe total number of clicks from Google search results that sent users to your site.
impressionsFLOATImpressionsThe total number of links to your site that users saw in Google search results.
ctrFLOATCTRClick-through rate: clicks divided by impressions.
positionFLOATAverage positionThe average ranking/position of your site's URLs in Google search results (1 is the top position).
