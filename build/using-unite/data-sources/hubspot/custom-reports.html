HubSpot Custom Report Fields

2,251 fields across 19 objects

Complete list of HubSpot fields that can be used in a Unite custom report. Use a custom report when the prebuilt reports do not include the fields you need.

Objects and fields​

HubSpot data is organized into objects, such as contacts, companies, and deals. Each field below is a property of one object, and a field ID can appear under more than one object. For example, hubspot_owner_id is available on many objects. Select the object first, then the fields you need from it.

Fields with the type enumeration accept one value from a fixed set of options defined in HubSpot.
